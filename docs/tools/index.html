The decline code dataset

The classification behind these tools is published as data as well as prose: stripe-decline-codes.json and stripe-decline-codes.csv. One record per decline code, with whether Stripe will execute a retry for it, whether it needs a new card, Stripe's recommended next step, the test card where Stripe publishes one, and the date the entry was last checked against Stripe's documentation.

It is generated from the same classifier that runs in the product, and a unit test fails the build if the two ever disagree. Free to use for anything, no attribution required.

Start with Stripe's own settings. Before any of these, check that Smart Retries and failed payment emails are switched on in your Stripe dashboard. They are free, they are genuinely capable, and for plenty of businesses they close most of the gap. The Stripe comparison page covers exactly what you already have.

Why these are free and unglamorous

Every one of these tools will, in some circumstances, tell you not to buy RecoverFlow. The estimator names a cheaper competitor when there is one. The retry builder tells you when the fix is an email rather than a product. The decline reference is just accurate information about Stripe with no pitch attached.

That is deliberate. RecoverFlow launched in July 2026 and has no customers to point at yet, so the only thing worth trading on is being accurate about a topic most content in this category gets wrong. If the tools are useful and the numbers are honest, that is a better argument than a testimonial we do not have.
