# Served on api.recoverflow.org and app.recoverflow.org (this API service).
# The marketing site at https://recoverflow.org is a separate origin (GitHub
# Pages) with its own robots.txt — nothing here affects it.
#
# Nothing on this host is meant to be indexed: the API endpoints require
# authentication and return 401 to anonymous crawlers, and the dashboard shell
# pages carry a `noindex` meta tag. We disallow the auth-gated paths so Googlebot
# stops crawling into them and reporting "Blocked due to unauthorized request
# (401)" in Search Console, while still allowing the HTML shells to be fetched so
# their noindex is seen and they drop cleanly out of the index.

User-agent: *
Disallow: /auth
Disallow: /connect
Disallow: /v1
Disallow: /webhooks
Disallow: /admin.html
Disallow: /hangfire
